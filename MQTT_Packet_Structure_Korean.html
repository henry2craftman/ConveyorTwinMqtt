고정 헤더는 최소 2바이트입니다

첫 바이트Type + Flags1 byte
이후 바이트Remaining Length1~4 bytes
그 뒤Variable Header + PayloadRemaining Length만큼
MQTT 전체 길이 = 1 + 길이 필드의 바이트 수 + Remaining Length

기억할 내용Fixed Header라는 이름이 길이가 항상 2바이트라는 뜻은 아닙니다. 실제 범위는 2~5바이트입니다.

MQTT 3.1.1 / 길이

Remaining Length를 계산합니다

321 = 65 + 2 × 128
첫 바이트: 65 + 128 = 193 = 0xC1
둘째 바이트: 2 = 0x02
결과: C1 02

각 바이트의 하위 7비트가 값이고, 최상위 비트는 다음 바이트가 더 있는지 나타냅니다.

기억할 내용C1 01을 같은 방식으로 해독하면 193입니다. 321의 올바른 인코딩은 C1 02입니다.

MQTT 3.1.1 / 인코딩

문자 수와 UTF-8 바이트 수

"unity-b"
길이: 7 bytes

00 07
75 6E 69 74 79 2D 62

앞의 두 바이트는 문자열 길이

  • 00 07은 뒤따르는 UTF-8 데이터의 길이입니다.
  • 길이 접두어 2바이트는 그 값에 포함하지 않습니다.

"가" → EA B0 80 → 3 bytes

두 전달 구간의 QoS는 독립적입니다

  1. ExplorerQoS 2 발행
  2. Broker구독 조건 적용
  3. Unity BQoS 0 구독이면 0으로 수신
