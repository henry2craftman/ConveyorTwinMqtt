DAY 01 / 개념 01

Unity에서 먼저 알아둘 여섯 가지

용어의미이번 실습의 예
Scene오브젝트를 배치하는 작업 공간현장 A / 원격 B
GameObject씬에 존재하는 대상컨베이어, 센서, 버튼
Component대상에 붙이는 기능Collider, Rigidbody, 스크립트
Transform위치·회전·크기SpawnPoint와 Motor Rotor
Prefab다시 생성할 수 있는 원본낙하할 제품
Inspector선택한 대상의 설정 화면스크립트 참조를 드래그하여 연결

확인 질문 · 완료 기준센서 오브젝트를 선택하고 Collider와 스크립트를 찾아본다.

강사 노트

Play 중 수정한 값은 종료하면 되돌아갈 수 있습니다. 실습 설정은 Play를 멈춘 상태에서 저장합니다.

DAY 01 / 개념 02

Unity A는 현장을 만들고, B는 상태를 봅니다

Unity A · 현장 시뮬레이션

  • 물체를 생성하고 물리 충돌을 처리합니다.
  • Mock PLC가 감지 입력을 보고 모터 출력을 결정합니다.
  • 계측값을 생성하고 MQTT로 발행합니다.

Unity B · 원격 뷰어

  • MQTT로 전달된 상태를 받습니다.
  • 모터·센서·계측 UI를 갱신합니다.
  • 오늘은 A를 완성하고, 2·3일차에 통신을 연결합니다.

확인 질문 · 완료 기준Gateway는 현장 데이터를 외부 메시지로 바꾸는 역할이라고 설명한다.

DAY 01 / 개념 03

X는 입력, Y는 출력, D는 수치

주소이 과정의 의미메시지 필드
X0근접센서의 물체 감지state.objectDetected
Y20컨베이어 모터 구동 출력state.conveyorMotorOn
D100온도 × 10measurements.temperatureC
D110진동 × 10measurements.vibrationMmS
D120전류 × 10measurements.currentA
D130RPM 정수measurements.rpm

확인 질문 · 완료 기준Start 버튼의 이벤트와 Y20 모터 출력을 구분한다.

강사 노트

새 컨베이어 교육용 주소입니다. 기존 MxPlcController에서는 Y20이 공급 실린더, Y26이 컨베이어이므로 실제 연동 시 매핑을 다시 맞춥니다.

DAY 01 / 실습 03 · 센서

센서가 감지 신호를 전달하게 만듭니다

  1. ProximitySensor의 Collider에서 Is Trigger를 켭니다.
  2. ConveyorProximitySensor의 Controller에 A의 컨트롤러를 연결합니다.
  3. Visual Sensor에 Controller와 같은 Sensor를 연결합니다.
  4. Required Tag를 사용한다면 제품의 Tag와 맞춥니다.
  5. 감지 해제 실습을 위해 Clear On Exit를 켭니다.

확인 질문 · 완료 기준제품이 들어올 때 X0가 true, 나갈 때 false로 바뀐다.

강사 노트

Trigger 이벤트에는 충돌 레이어와 Rigidbody 조건이 맞아야 합니다. 이 센서 코드는 단순 진입·이탈 방식이므로 먼저 제품 하나로 실습합니다.

DAY 01 / 실습 04 · 버튼

Start 버튼에서 모터 출력까지 추적합니다

  1. Button의 On Click()에 컨트롤러 오브젝트를 넣습니다.
  2. 함수 목록에서 PressStartButton()을 선택합니다.
  3. Play 후 한 번 클릭하여 물체가 생성되는지 확인합니다.
  4. Inspector의 X0 Object Detected가 켜지는지 봅니다.
  5. Y20 Conveyor Motor On과 컨베이어 움직임을 확인합니다.

확인 질문 · 완료 기준버튼 → 생성 → X0 → Mock PLC → Y20 순서로 설명한다.

강사 노트

PressStartButton()은 물체 생성 이벤트입니다. startButton=false만으로 모터가 정지하는 로직은 아닙니다.

DAY 01 / 실습 05 · 정지

감지가 풀리면 컨베이어가 멈추게 합니다

두 설정을 함께 변경

컴포넌트설정
Mock ControllerLatch Motor After Detection = OFF
Proximity SensorClear On Exit = ON

확인할 결과

  1. 제품 진입X0 ON → Y20 ON
  2. 제품 이탈X0 OFF → Y20 OFF

자기 유지를 켜면 감지가 풀려도 출력이 유지됩니다.

확인 질문 · 완료 기준제품 한 개를 완전히 통과시켜 감지와 모터 출력을 함께 관찰한다.

강사 노트

짧은 입구 센서만 사용하면 제품이 목적지에 도달하기 전에 멈출 수 있습니다. 실제 운전에는 출구 센서·타이머·운전 시퀀스가 필요할 수 있습니다.

DAY 01 / 실습 06 · UI

숫자와 Filled 게이지를 연결합니다

  1. Canvas에 RPM·온도·진동·전류의 TMP Text를 배치합니다.
  2. 각 게이지 Image에 Sprite를 지정하고 Image Type = Filled로 설정합니다.
  3. Fill Method를 Horizontal 또는 Radial 360으로 정합니다.
  4. ConveyorDashboard의 Text와 Fill 필드를 각각 연결합니다.
  5. Controller의 Dashboard에 연결하고 Color Gauge By Value를 켭니다.

확인 질문 · 완료 기준수치와 게이지가 함께 변하고, 텍스트가 게이지를 가리지 않는다.

강사 노트

fillAmount는 값 ÷ 최대값을 0~1로 제한한 값입니다. 예: 온도 50°C / 최대 100°C = 0.5.
